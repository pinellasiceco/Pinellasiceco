# Google Business Profile playbook — the map-pack battlefield (operator actions)

Lane 3's real fight happens in GBP, not on the site. The site side (NAP,
LocalBusiness schema with geo + hasMap, sales-first Service schema, landing
pages) is done; everything below is yours. Ordered by leverage.

## 1. Category decision (sales-first)

- **Primary category: "Ice machine supplier"** (exists in GBP's taxonomy) —
  this is the sales-first call and what the map pack keys on hardest.
- Secondary categories: "Appliance repair service" (covers repair),
  "Commercial refrigerator supplier" if offered, and keep any cleaning-
  adjacent category currently set — don't discard existing category equity
  without checking what the profile ranks for today.
- NAP must match the site exactly: **Pinellas Ice Co · (727) 855-6873 ·
  Clearwater, FL** (service-area business — hide street address if no
  storefront, list the service areas below).

## 2. Service areas + services list

- Service areas: Tampa, St. Petersburg, Clearwater, Largo, Dunedin, Palm
  Harbor, Brandon, Pinellas Park, Tarpon Springs (GBP allows ~20 — use the
  cities, not just counties).
- Services (add each as a named service with description):
  - Commercial ice machine sales (new & used)
  - Ice machine leasing
  - Commercial ice machine repair
  - Ice machine cleaning & sanitizing (ATP-verified)
  - Ice machine installation
  - Ice machine haul-away & replacement
- Link each service description to the matching page (sales →
  /commercial-ice-machine-sales/, etc.). Website field → homepage;
  appointment link → /contact/.

## 3. Products section (free merchandising — most local competitors skip it)

Add "products" for the offer shapes, not inventory pretense:
- "$99 Initial Clean & Test" → Tier A Clearwater page
- "Ice machine sizing + quote (free)" → /ice-machine-cost-calculator/
- "Service lease — from ~$110/month" → /ice-machine-lease-cost/
- "Replacement with haul-away" → /replacing-a-commercial-ice-machine/

## 4. Reviews (the #1 map-pack ranking + conversion input)

- Ask EVERY completed job, same day, by text with the direct review link
  (GBP → Ask for reviews → copy link). Same-day ask converts several times
  better than a week later.
- Respond to every review within a day or two — responses are a ranking
  and trust signal.
- Never incentivize or gate reviews (policy violation risk).
- When reviews exist, paste real ones into `src/components/ui/Reviews.astro`
  to light up the site's review sections (shipped empty on purpose).

## 5. Posting cadence

- One GBP post per week is plenty: rotate seasonal repair
  (summer/hurricane — link /hurricane-season-ice-machine/), a decision-
  library guide, and an offer post ($99 clean, free sizing).
- Add 3–5 real photos per month (trucks, installs, before/after cleanings —
  real beats polished).

## 6. Citations checklist (NAP-identical everywhere)

Same name, number, and locality as GBP + site, character for character:
- [ ] Bing Places
- [ ] Apple Business Connect
- [ ] Yelp
- [ ] Industry directories (2–3): e.g. Restaurant Depot-adjacent local
      supplier lists, Florida Restaurant & Lodging Association vendor
      directory, Chamber of Commerce (Clearwater and/or St. Pete)
- Citation consistency + review velocity are the two highest-leverage
  local inputs outside the site itself.

## 7. Watch

- GSC: expect Lane 1/4 query impressions in 30–60 days.
- GBP Insights: watch "ice machine supplier near me"-class discovery
  searches; map-pack movement tracks the review count + category change,
  usually inside 60–90 days.
- Head terms ("commercial ice machine tampa"): not before 2027 — measure
  the lanes, not the head.
